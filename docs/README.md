# Documentation

Mangekyo Agent is an open-source agent runtime for version control. The runtime implementation and install instructions have not been published yet.

## Project links

- [Repository](https://github.com/jweng121/mangekyo-agent)
- [Issues](https://github.com/jweng121/mangekyo-agent/issues)

- [Apache 2.0 license](../LICENSE)

## Language

The current README and documentation are in English. Implementation languages and supported platforms will be documented when runtime code is available.

## Brand assets

The terminal UI uses the Classic Scarlet banner. The dashboard uses the red Mangekyo emblem, and GitHub uses the full `MANGEKYO-AGENT` wordmark. See the [asset guide](../assets/README.md) for exact files and color values.
